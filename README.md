## 频段、APN与设备兼容性：搞定设置才能畅快上网

　　买到卡只是第一步，插卡就能用的日子在这里不一定每次都能实现。利比里亚主要采用4G LTE网络，兼容Band 3(1800MHz)和Band 20(800MHz)等常见频段，绝大多数国产全网通手机都能支持。

　　但**APN（接入点）设置是关键！** 很多情况下需要手动设置才能激活数据服务：
-   Lonestar Cell MTN: APN设置为 `internet`
-   Orange Liberia: APN设置为 `orange.liberia`
　　（设置路径通常在“移动网络”设置中，找不到可以随时请店员帮忙弄一下，他们很熟练。）

　　说到设备，别忘了确认你的手机没有运营商网络锁。另外，虽然利比里亚也在推广5G，但2025年主要还是4G的天下，所以别对5G速度抱太高预期——稳定的4G已经谢天谢地了。
